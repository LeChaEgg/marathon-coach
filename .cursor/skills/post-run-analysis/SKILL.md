# 跑后分析

## 流程

1. 运行分析（默认最近一次跑步；也可传活动 ID 或日期；需要 `full_network`）：
   ```bash
   python3 -m coach run            # 或 python3 -m coach run 2026-09-27 / i190804994
   ```
   如果最近一次跑步不是用户刚说的那次（手表还没同步到 Intervals），告诉用户稍后重试，不要分析旧的那次来冒充。
   命令会顺带更新静态看板 `reports/dashboard.html`；训练中心网页实时读取，不需要额外操作。
2. 检查自动分类（报告标题行）。如果和实际课型不符（比如计划是节奏跑却被分成轻松跑），先修正再重跑：
   ```bash
   python3 -m coach log --activity <ID> --type tempo && python3 -m coach run <ID> --offline
   ```
3. 读取本周计划 `plan/weeks/<本周>.md`，对照计划看完成度。
4. 用户在消息里给了反馈的，立即记录：
   ```bash
   python3 -m coach log --activity <ID> --rpe 6 --pain 1 --pain-loc "左胫骨内侧下1/3" --pain-when 跑后 --gait 正常 --fatigue "后5km腿沉" --fuel "无" --note "..."
   ```
   有骨性压痛、跳跃痛、跛行、疼痛持续到次日时加 `--red-flag`。
5. 写分析（格式见下），并追加到 `reports/runs/<日期>_<ID>.md` 的 `## 教练结论` 一节。
6. 用户还没给主观反馈的，在结尾按固定清单请他补充（也可以在训练中心网页的跑步详情页填表提交，效果等同 `coach log`）。
7. 结论写入报告文件后，训练中心网页会自动显示，不需要再运行任何命令。

## 分析要点（按课型挑重点，不要把报告复述一遍）

- **轻松/恢复跑**：心率是否守住上限；AeI 与同类中位数、近 28 天的对比；脱钩；步频、触地是否稳定。
- **长距离**：配速与心率的后程漂移（第 1/3 → 第 3/3）、脱钩（<5% 良好）、跑姿后程变化、补给；和上一次长距离比，同样距离心率更低或配速更快吗？
- **节奏/阈值**：连续 Z3+/Z4+ 的时长、这一段的配速和心率、后段有没有掉速；和上次同类课比较同心率下的配速。
- **间歇**：每组配速 CV、首末组差异、组间 60 秒心率回落（回落变多说明恢复能力在提高）、最后几组有没有掉速。
- **能力变化**：只有 AeI、EF、快段配速这类指标变化 ≥5 s/km 或 ≥3%，并且和之前的趋势一致时，才写“能力提升/下降”。单次跑的波动先考虑天气、路线、睡眠、前一天负荷。
- **跑力评分（报告第 2 节）**：引用综合跑力和该课型对应的维度（轻松跑看有氧，节奏跑看阈值，间歇看速度，≥60 分钟的跑看耐力），并与“近28天中位”比较。单次差异在 ±1.5 分以内都算正常波动；超出时先检查睡眠、天气（已做部分修正）、RHR 来源（`wellness7日中位`/`默认值` 的可靠性较低）和置信度。低置信度（跑步机、证据少）的评分不作为能力判断依据。能力趋势以“状态跑力”为准，不以单次分数为准。
- **子项贡献表（报告第 2 节末尾，每次跑后必须评论）**：对有氧/阈值/速度/耐力逐项告诉用户“这次有没有提升”：提升信号 / 持平 / 低于状态 / 无法判断（写原因）/ 未涉及。单次判断的是“在噪声内/弱信号/明显”（按子项 σ），多数是“在噪声内”——这是正常的，不要把它写成提升或下降；真正回答“这周有没有变强”的是“本次状态变化”和“本周累计 ± 标准误”，要引用。某个子项该课型应该练却“无法判断”，或某子项 ≥14 天没有新证据，要点名并建议改哪节课（见表下注），必要时在下一步调整课表。目标是每次跑都有针对性的小贡献。
- 评分只是模型估计：不要把单次分数当作比赛能力，也不要用它推算成功率。
- **伤病风险信号**：后程触地时间上升 >5ms、步频下降 >3spm、单侧疼痛、心率异常偏高 → 明确写出来，并给出对明天训练的影响。
- 跨设备（Garmin/Apple）或跑步机的对比只作方向参考，要写明。

## 输出格式

```markdown
**一句话结论**：完成度 + 最重要的发现

**子项贡献**：有氧 …／阈值 …／速度 …／耐力 …（提升/持平/低于/无法判断+原因）；未更新的子项怎么补

**跑力评分**：综合 xx.x（距破3 −x.x，置信度 x）；主要维度 xx.x vs 近28天中位 xx.x；状态跑力 xx.x

**关键数据**（3–6 行，带数字和对比）
- ……

**与同类跑步对比**：……（能力趋势，附 n 和时间跨度）

**做得好 / 需要改进**：……

**对接下来训练的影响**：明天建议 …；本周剩余安排是否调整 …

**请补充反馈**（如未提供）：实际距离/时间、RPE 1–10、跑中/跑后/次日疼痛及位置、步态是否改变、异常疲劳、补给
```
