# 周复盘与下周计划

## 流程

1. 运行周报（周日当天默认复盘本周，其他日子默认复盘上一个完整周；也可传该周任意日期；需要 `full_network`）：
   ```bash
   python3 -m coach week
   ```
2. 读取对照材料：
   - `plan/weeks/<本周>.md`：计划 vs 实际
   - `plan/season_plan.md`：阶段目标与检查点
   - 上一份 `reports/weekly/*.md` 的 `## 教练结论`：上周定下的重点完成了没有
   - 本周 `reports/runs/` 里的教练结论（如果有）
3. 本周 journal 没有疼痛/疲劳记录时，在输出里请用户补充。用户已经给了的，用 `python3 -m coach log` 记下来。
4. 写复盘（格式见下）。
5. 把下周计划写入 `plan/weeks/<下周>.md`（格式见下）。每天一行，以 `周X MM-DD：` 开头，晨报靠这个格式找到当天的条目。
6. 如果实际进度和赛季计划偏离较大（受伤、生病、明显超前/落后），修改 `plan/season_plan.md` 中后续几周的行，并在文件末尾加一条“修订记录”。
7. 把复盘结论追加到 `reports/weekly/<本周>.md` 的 `## 教练结论`。
8. 计划和结论写入文件后，训练中心网页（`python3 -m coach serve`）的「本周」「赛季」页会自动显示，不需要再运行任何命令。

## 判断要点

- 下周跑量看报告第 9 节：规则区间、长距离上限、质量课次数，以及它与赛季计划怎么取舍，都由 `athlete.toml [plan] aggressiveness`（1 保守 – 5 激进，参数见 `coach/style.py`）决定。按当前档位执行，不要自行再保守一档；有疼痛时再下调。
- 档位只改变负荷规则。疼痛 ≥3、骨性压痛、跳跃痛、跛行按 AGENTS.md 红绿灯处理，所有档位都一样。4–5 档时，在「本周注意」写明每天早上的胫骨按压和单脚跳检查。
- 用户在训练中心「赛季」页调整档位时，页面已经改好 `[plan] aggressiveness`；你按要求重排本周剩余天数或修订赛季计划，并记录修订原因。近期有疼痛 ≥3 或红旗反馈时，先说明并建议退回原档位。
- 加量周不加难度；新增课型的那周跑量持平。连续加量达到档位规定的周数后安排减量周。
- 轻松跑时间占比保持 ≥75%；长距离里的马配段算一次质量课。
- 攀岩/骑行安排要避开质量课和长距离的前一天。
- 能力分析用多周趋势（12 周表、28 天 vs 前 28 天）；单周波动不下结论。
- 报告第 7 节开头的“跑力评分趋势”给出各维度的状态值（VDOT 刻度，破3 ≈ 53.6）。能力分析表里每一行都要引用对应维度的状态值和 4 周变化；带 * 的维度 42 天内没有新证据，要写明“缺少近期数据”，不能当作能力没变。维度之间的差距本身是信号（例如阈值明显低于有氧 → 阈值是短板）。
- 同一节的“破3准备度”给出难度加权进度、相对所需进度线的领先/落后、所需进步速度占历史最快 8 周的比例，以及 Tanda 跑量判断。周复盘要引用：落后于进度线 ≥1 分，或所需速度 ≥100% 历史最快时，明确写出目标风险，并在测试周（W43/W51/2027-W02）用实测成绩重新评估。它是模型估计，不是成功率。
- 复盘结尾提醒用户可以打开训练中心网页（`python3 -m coach serve`，「赛季」页看计划与实际对比）。
- 破3差距只列最关键的 2–3 项，并说明下周哪次课是针对它的。
- 成绩预测给区间，并说明各模型的局限；不提供没有依据的成功率。

## 复盘输出格式

```markdown
## 本周小结（W..）
- 跑量/次数/最长/质量课 vs 计划：……
- 强度分布、其他运动、恢复、伤痛：……

## 能力分析
| 能力 | 本周信号 | 趋势（4–12周） | 判断 |
|---|---|---|---|
| 综合跑力（状态值/距破3/破3进度） | | | |
| 有氧（有氧跑力、AeI/心率曲线） | | | |
| 耐力（耐力跑力、保持率、长距离、脱钩） | | | |
| 阈值（阈值跑力） | | | |
| 速度/VO₂（速度跑力） | | | |
| 跑姿经济性 | | | |
| 伤病韧性（跑量耐受、疼痛） | | | |

## 距破3的差距（按优先级）
1. ……（当前 vs 需要，计划用什么课来补）

## 下周计划要点
- 目标跑量 …km｜长距离 …｜质量课 …｜本周重点 …
```

## 下周计划文件格式（plan/weeks/YYYY-Www.md）

```markdown
# 2026-W40 训练计划（09-28 ~ 10-04）

阶段：A 重建适应｜目标跑量 50 km｜长距离 17 km｜重点：……

- 周一 09-28：休息 / 轻松攀岩（≤1.5h，不做力竭）
- 周二 09-29：轻松跑 8km，HR ≤147；结束后 6×20s 加速跑（平路，放松）
- 周三 09-30：……
- 周四 10-01：……
- 周五 10-02：……
- 周六 10-03：……
- 周日 10-04：长距离 17km，HR 145–150，平路上限 156

## 本周注意
- ……（伤痛观察点、调整规则、补给/力量）
```
